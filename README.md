# TD 235 拍照維修助手

TAICA「生成式AI：文字與圖像生成的原理與實務」期末個人專案。

拍一張 Thorens TD 235 唱盤零件或故障處的照片、打一句症狀，AI 先看懂照片，再到原廠說明書裡找出對應段落，回答可能原因與維修步驟（標註頁碼），並附上說明書插圖。

- 延伸自第七週作業「TD 235 唱盤技師」（[td235-rag](https://github.com/RogerH0711/td235-rag)），檢索與回答的核心沿用該作業
